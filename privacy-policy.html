Privacy Policy for Shorts Agent

Last updated: November 19, 2026

Shorts Agent is a personal tool operated by Zulkarnain to upload videos to his own YouTube channel, Wirestory. It is used only by the channel owner.

Use of YouTube API Services

Shorts Agent uses YouTube API Services. By using Shorts Agent, you agree to be bound by the YouTube Terms of Service. Google Privacy Policy: https://policies.google.com/privacy

What information is accessed and why

With the owner's permission (Google sign-in, scope: youtube.upload), Shorts Agent uploads videos that the owner has created and approved to the owner's own YouTube channel. It does not read, collect, or store any other YouTube data, and it does not access data about any other users or viewers.

What is stored

The only data stored is the owner's own Google OAuth sign-in token, kept on the owner's own computer so approved videos can be uploaded. No data is stored on any server.

Sharing

No data is sold, shared, or disclosed to any third party. This website uses no cookies or tracking.

Revoking access

Access can be revoked at any time through Google's security settings: https://myaccount.google.com/permissions

Data deletion

To delete all stored data, revoke access at the link above and delete the token file from the computer running Shorts Agent. Any deletion request sent to the contact email below will be completed within 7 days.

Changes

Any changes to this policy will be posted on this page with an updated date.
